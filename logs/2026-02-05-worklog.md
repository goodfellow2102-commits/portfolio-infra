# 作業ログ — 2026-02-05

## 実施内容

### ■ Zabbix 監視環境の確認・調整
- Zabbix サーバUIにログインしてダッシュボードを確認
- Hosts / Problems / Latest data の画面構成を把握
- 監視対象ホスト（Web / DB）の登録状態を確認
- トリガー・アラート表示の見方を整理

確認項目：
- Host 登録有無
- Agent 通信状態
- 最新データ取得可否
- Problem 一覧表示動作

---

### ■ Zabbix Agent 設定確認
- 監視対象サーバ側の agent 設定ファイル確認
- server / serveractive / hostname の設定値チェック
- サービス起動状態を確認

確認コマンド：
- `systemctl status zabbix-agent`
- `ss -lntp | grep 10050`
- `grep Server /etc/zabbix/zabbix_agentd.conf`

---

### ■ 監視通信の疎通確認
- 監視サーバ → 対象サーバ間の通信確認
- ポート開放状態の確認
- Firewall（ufw）設定の見直し

確認コマンド：
- `ufw status`
- `ss -lntp`
- `ping <監視対象IP>`

---

### ■ ポートフォリオ構成の拡張検討
- メールサーバ構築の可否を検討
- 現行構成（Web / DB / Monitor）からの拡張パターンを整理
- 優先度を下げて後回しにする方針を決定

---

## 発生した課題
- Zabbix 画面項目が多く、機能の切り分けに時間がかかった
- Agent 設定値とホスト登録名の不一致リスク
- Firewall と監視通信の関係整理が必要

---

## 学習ポイント
- Zabbix は「Agent設定＋UIホスト設定」の両方一致が必要
- 監視はポートとFW設定の理解が必須
- 作業ログは即時 md 化すると後のREADME作成が楽になる
